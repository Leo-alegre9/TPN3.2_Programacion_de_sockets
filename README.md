# TP 3.2 - Programación de Sockets

Trabajo práctico de la materia **Redes de Datos** de la Licenciatura en Sistemas de Información.

El proyecto implementa una arquitectura **cliente-servidor** mediante sockets TCP.

## Contenido

- Servidor de chat desarrollado en Python.
- Cliente de chat desarrollado en Python.
- Cliente adicional desarrollado en Java.
- Comunicación entre múltiples clientes.
- Comandos `/listar` y `/quitar`.
- Manejo de conexiones y desconexiones.
- Análisis del tráfico generado mediante Wireshark.

## Tecnologías utilizadas

- Python
- Java
- TCP/IP
- Wireshark
